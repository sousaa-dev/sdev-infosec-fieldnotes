# SDEV · Information Security Field Notes

![Focus](https://img.shields.io/badge/Focus-Blue%20Team-12345A) ![Language](https://img.shields.io/badge/Language-PT--BR-009B77)

## 🇺🇸 English

A structured learning repository on information security and defensive operations. It includes a Portuguese study workbook, individually editable chapters, case studies, practical exercises and assessment criteria. It connects security fundamentals to governance, infrastructure administration and incident management.

## 🇧🇷 Português

Uma base de conhecimento de segurança da informação organizada para estudo progressivo e aplicação prática. Cada capítulo combina conceitos técnicos, cenário fictício, atividade e critérios de avaliação. O material pode ser utilizado como roteiro de revisão, treinamento e desenvolvimento de documentação de segurança.

## Como estudar

1. Leia os fundamentos e registre dúvidas.
2. Resolva os casos usando dados simulados.
3. Produza os artefatos solicitados e compare com os critérios de aceitação.
4. Integre os controles no projeto final e revise as fontes primárias.

## Organização

- `pdf/`: caderno didático para leitura offline.
- `chapters/`: capítulos editáveis e atividades.
- `templates/`: modelos reutilizáveis de documentação.
- `notes/`: anotações introdutórias anteriores.
